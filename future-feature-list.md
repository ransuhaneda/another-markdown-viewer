# Future feature list

This file is a parking lot.
It is not a roadmap.
It contains no estimates or priority order.

Do not implement an item without an explicit product decision.

## Deferred product features

- Multiple document tabs.
- Folder or project browsing.
- Cloud synchronization.
- Collaboration.
- User accounts.
- Version history.
- A plugin system.
- Git integration.
- Image upload and asset management.
- Full mobile editing.
- User-selectable visual themes.
- Custom CSS and rendered-document theme controls.

## Deferred Markdown dialects

- CommonMark as a separate selectable or extended compatibility target.
- Markdown Extra.
- Footnotes if they require special product behavior.
- LaTeX math rendering for inline and display equations.

## Possible later improvements

- A local document library.
- More recovery history.
- IndexedDB recovery for larger documents.
- A configurable command palette.
- Expanded code-language support.
- More advanced image layout helpers.
- A dedicated PDF generation path if browser print styles cannot meet the quality contract.
- Installable offline PWA behavior.
- Additional browser and mobile verification tooling.
- MD-Files came from obsidian, wich has a lot of yaml-Information in the header.
- use highlight.js or a more broad syntax highlighting
- Render Mermaid diagrams (flowcharts, sequence diagrams, Gantt charts, and other supported diagram types) from Mermaid fenced code blocks.
